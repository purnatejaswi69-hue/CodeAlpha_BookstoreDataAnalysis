# CodeAlpha Bookstore Data Analysis

## Project Overview

This project was completed as part of my CodeAlpha Data Analytics Internship.

The project focuses on collecting, analyzing, and visualizing book data using Python.

## Tasks Completed

### Task 1 - Web Scraping

Book data was collected from Books to Scrape using Python, Requests, BeautifulSoup, and Pandas.

The dataset contains:

- Book Title
- Price
- Rating
- Availability
- URL

A total of 1,000 books were collected and saved as `books.csv`.

### Task 2 - Exploratory Data Analysis

Exploratory Data Analysis was performed using Pandas to understand:

- Dataset structure
- Data types
- Missing values
- Summary statistics
- Rating distribution
- Availability
- Duplicate records
- Book prices and ratings

### Task 3 - Data Visualization

Visualizations were created using Matplotlib and Seaborn, including:

- Rating Distribution
- Price Distribution
- Top 10 Most Expensive Books
- Price Distribution by Rating
